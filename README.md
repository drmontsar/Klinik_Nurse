# KliniK Nurse

Angular 22.2 bedside workspace for the KliniK platform. Includes the ward queue, task filters, observation entry, medication confirmation, device note drafts, and embedded shift handover.

## Run

Start the API and gateway using [the project setup guide](../klinik-platform/docs/angular-setup.md), then:

```sh
cd "/Users/abhishikthjosemenacherry/Documents/Ideas/Klinik/KliniK-Nurse"
nvm use 24.21.0
corepack enable
pnpm install --frozen-lockfile
pnpm run ui
```

`pnpm run dev` is the same UI command. Open **http://localhost:8080/nurse/**. Port 5173 serves the Angular development app at `/nurse/`.

Local development creates the synthetic Nurse session without a password. Normal mode uses authenticated API repositories; synthetic device-only demo mode must be explicitly opened at `/nurse/?demo=1` in a development build. Production ignores that demo flag. API errors never switch to demo records.

## Build

```sh
pnpm run typecheck
pnpm run build
```

The production browser artifact is `dist/klinik-nurse/browser/`. Mount it at `/nurse/` behind the API gateway. Angular service worker caches app assets in production; private API and authentication responses are not cached.

The existing GitHub Pages workflow uses the new artifact path. A connected clinical deployment still requires the platform API and its same-origin gateway at the configured path.

## Safety and persistence

- Medication confirmation starts unchecked and is required for administration.
- Missing observations remain null; incomplete NEWS2 is shown as incomplete. The server calculation is authoritative.
- Network-failed versioned commands stay in the existing identity/organization-specific Dexie queue. Device save is visibly distinguished from server confirmation.
- Reconnection replays only under the matching session. Stale or forbidden commands require review.
- Nurse scratch notes remain unsigned device drafts. API-mode drafts are separated by identity and organization.
- Existing demo task/vitals storage keys and offline command database names are retained.
